    Install Nexyl

    This browser did not offer a one-tap install, so add it from the browser menu:

    • iPhone / iPad (Safari): tap the Share button, then “Add to Home Screen”.
    • Android (Chrome): open the menu, then “Install app” or “Add to Home screen”.
    • Desktop (Chrome / Edge): use the install icon in the address bar, or the menu’s “Install Nexyl.ai”.

    Once installed, Nexyl opens in its own window and keeps working offline for anything already cached.
